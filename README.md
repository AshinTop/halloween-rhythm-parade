# Halloween Rhythm Game — Midnight Rhythm Parade

**Four little monsters. Three original songs. One glowing Halloween street.**

Midnight Rhythm Parade is a complete, browser-based Halloween rhythm game with four note lanes, touch controls, keyboard play, and original music synthesized with Web Audio. Catch pumpkin lanterns, ghost notes, and crystal beats as they meet the gold line. Build a 20-note combo to light up the parade, then chase a better performance or slow the music down for a gentle rehearsal.

Part of **Midnight Candy Club**, created for the Halloween collection at [sprunki-game.top](https://sprunki-game.top).

## Why play this Halloween music game?

- **Three complete original tracks**, each approximately 49–50 seconds at normal speed, with different melodies, rhythmic patterns, and energy.
- **Four recognizable note shapes** and four monster buttons: a pumpkin, velvet cat, shy ghost, and little bat. Color is supported by shape and lane position.
- **Real timing judgements**: Perfect within ±55 ms, Good within ±115 ms, and Okay within ±180 ms. Missing a note breaks the combo while the song continues.
- **Lantern Fever** after 20 consecutive hits. The score multiplier grows with the combo, up to a 50% bonus.
- **A 75% speed practice mode** that keeps the complete note pattern and does not replace the normal-speed best score.
- **Pause and resume**, including automatic pause when the page becomes hidden or audio playback is interrupted.
- **Timing adjustment from −150 ms to +150 ms** for a more comfortable match between your device’s audio and the visual notes.
- **English and Simplified Chinese**, local best scores, optional sound, and shareable song links.
- **No installation, account, external audio files, runtime libraries, or CDN requests.** The game can be hosted as a small static site.

Each song includes a four-beat count-in. The music is written for this project and generated by browser oscillators and deterministic noise percussion; it is not a recording or a modified third-party soundtrack.

## How to play

1. Choose a song and optionally enable **Practice · 75%**.
2. Press **Start the parade**. Audio starts only after your interaction.
3. Watch the falling notes. Hit the matching lane when a note reaches its glowing target on the gold line.
4. When two notes arrive together, hit both lanes together.
5. Continue to the result screen to see your score, accuracy, best combo, and judgement counts.

There is no early-failure health bar. A difficult phrase is a chance to recover your rhythm, and every song can be played to its conclusion.

### Controls

| Action | Keyboard | Touch / mouse |
| --- | --- | --- |
| Lane 1–4 | **D, F, J, K** | The four monster buttons |
| Start, pause, resume | **Space** outside form fields | Main transport button |
| Choose a track | Focus the song selector | Song selector |
| Timing calibration | Focus the settings controls | Gear button |
| Help, restart, share | Standard button navigation | Corresponding buttons |

The game supports simultaneous touches for chords. Key-repeat does not generate repeated rhythm hits. Scores are awarded only when an unjudged note in the correct lane is inside its timing window.

## Sharing, records, and privacy

A link such as `#song=velvet-wings&practice=1` opens the same song and practice setting. It does not upload a recording or start the music automatically.

Language, sound preference, timing offset, and normal-speed best scores are stored in the current browser. Storage is optional: blocked storage or malformed saved data falls back safely. An unfinished performance is not restored after navigating away.

## Run locally

Serve the repository through HTTP so the browser can load ES modules:

```sh
python3 -m http.server 4173
```

Open `http://localhost:4173/`. No dependency installation or build step is needed.

Run the automated checks with Node.js:

```sh
npm test
```

There are **13 focused tests** across the core game, real audio transport and UI startup flow. They cover every chart, complete all-perfect playthroughs, exact timing-window boundaries, duplicate-hit prevention, miss accounting, practice timing, invalid preferences and share links, bounded audio scheduling, long frozen-tab jumps, pause/resume, cancellation of asynchronous starts, stopping queued audio sources, and a late rejected startup promise after a newer performance has begun.

## Embedding and browser support

The layout fills its actual iframe viewport and keeps gameplay controls available at desktop, portrait-phone, and short-landscape sizes. Designed integration frames include **1160 × 654**, **390 × 650**, **390 × 794**, and **844 × 340** CSS pixels. See [EMBEDDING.md](EMBEDDING.md) for the host contract and verification limits.

```html
<iframe src="https://ashintop.github.io/halloween-rhythm-parade/"
  title="Midnight Rhythm Parade" width="1160" height="654"
  allow="autoplay; fullscreen" allowfullscreen
  style="display:block;width:100%;border:0"></iframe>
```

Use a current browser with Canvas 2D, ES modules, and Web Audio. Sound is subject to device volume, browser permissions, and audio-output latency. The automated tests verify scheduling and game logic; they do not measure real acoustic latency or substitute for listening on a physical device.

## Frequently asked questions

**Is this a Sprunki mod?**  
No. This is an original four-lane rhythm game in the same Halloween collection as [Pumpkin Jam](https://github.com/AshinTop/halloween-sprunki).

**Can I play on a phone?**  
Yes. The four bottom buttons support touch, including multi-touch notes. Landscape and portrait layouts are supported.

**Why did the music pause when I switched apps?**  
The game pauses hidden or interrupted playback so it does not replay a backlog of missed audio. Press Resume when you return.

**Does practice replace my record?**  
No. The 75% speed mode is a rehearsal; normal-speed records remain separate.
